## 4. Reply patterns that worked vs failed

### Worked (got human substance)

| Pattern | Example |
| --- | --- |
| Reply to **their** bill/stack story, not a generic compliment | Kabandi stack list; Jithin Cursor cost |
| One concrete question (yearly vs monthly; calculated vs freak-out) | Jithin long answer |
| Respect soft solutions (“sheet works”) then probe gap | Kabandi path |
| Founder-to-founder honesty with adjacent | Ahmad aggregators answer |
| Distinction questions (usage cost vs renewals) | Arpit follow-up design |

### Failed or weak

| Pattern | Why |
| --- | --- |
| Old LinkedIn post links (weeks/months) | Low engagement; feels spammy |
| DM same question while they only answer public | Jithin ignored DM |
| Defending third-party claims in drama threads | Quby vs Jithin $10k — stay out |
| Pitching product on a joke beat | Feifei meta-joke |
| Long paragraphs / feature lists | Not used; banned |
| Offering free custom builds (Founder OS) | Trap — refuse |

### Channel rules (learned)

| Channel | Rule |
| --- | --- |
| **X** | Best for live pain posts; public replies > cold DM first |
| **DM** | After engagement or extreme HOT evidence; one clear research Q; no double-text same day |
| **LinkedIn** | Only posts **≤7 days** (prefer 48h). Profile → Posts → Recent. No indexed-zombie links |
| **Peerlist** | Good for solo SaaS intros; comment on their show post |

## 6. Scripts bank (copy that matched field reality)

### 6.1 Public reply — stack / bill pain

```
[specific number or tool from their post] is brutal.

without opening N tabs — do you actually have one place that shows when these renew + the annual total? or is it still card-statement hope?
```

### 6.2 After “I use a spreadsheet”

```
fair — most founders land on a sheet.

how often does something still surprise you — renewal you forgot to log, or annual that hits while the sheet is stale?
```

### 6.3 After “we already track cost” (AI infra)

```
smart.

is that mostly runtime/LLM usage, or also boring renewals (saas seats, cloud commits, domains) with dates for the next 30–45 days?
```

### 6.4 Research DM (not pitch)

```
hey — saw [specific].

random founder question: do you know every saas/ai/cloud/domain renewal in the next 30–45 days without digging invoices?

not selling — trying to understand how people handle it today.
```

### 6.5 Live test offer (only after “I don’t know / chaos / sheet stale”)

```
that's exactly what i'm looking at.

if you're up for it: 2–3 redacted invoices (no bank login). i'll map next 45 days + what it finds. only useful if it beats memory/sheet — otherwise ignore me.
```

### 6.6 Adjacent founder (Veluri-class)

```
[specific product choice] is rare/smart.

founder to founder: [one question — why no bank / first action / what users refused / first 10 channel]?

building in a related space — comparing notes, not converting you as a user.
```

### 6.7 Problem-led X post (ICP replies, no product)

```
Founders (especially India):

without opening Stripe, Gmail, your bank, or a spreadsheet—

how much money is scheduled to leave in SaaS + AI + cloud + domain renewals over the next 45 days?

Exact number. Not approximately.

A) I know exactly
```
