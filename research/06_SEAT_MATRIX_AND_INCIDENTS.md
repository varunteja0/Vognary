## 2. Trader-world anchor — where verification IS bought, and where it isn't (for breadth seat #26)

Verified estimates (non-audited, third-party modeled — cite with caution):
- Retail funded-trader (evaluation) segment revenue ≈ **$4.0–4.5B in 2026**, ~720k active funded accounts (proprietarytrading.com data page / Octrado bottom-up-top-down ~$3.8–5B; Track360's narrower retail-only estimate ~$850M) — sources disagree; use ranges.
- **5–14% pass evaluations; ~7% of buyers are ever paid.**
- **60–70% of account failures end by RULE BREACH (daily/max drawdown), not by bad strategy** (hoc-trade 500k-trader analysis; Track360 cohorts). FPFX Tech's 300k-account study: 14% pass, 7% payout.
- Rule engines exist that force-close on unrealized loss caps (Blue Guardian "Guardian Shield", FundingPips funded-stage cap, HyroTrader 5-min stop-loss) — i.e., **the trading world already institutionalizes per-transaction risk verification — inside PROPS, sold B2B by tech vendors — while retail traders buy nothing.**

Formal lesson (matches the founder's testimony): **retail traders = habituated, zero-pay journal category (round-1 ceiling ~$100–150M/yr). Institutions that let OTHERS trade = pay for rules/verification engines.** Seat #26 (prop-firm ops head) stays in the breadth set for the SAME reason our current primary direction is not trading: the buyer of authorization-verification there is a firm, not a person's habit. ## 5. Current-state workflow sketch (brief, for credibility on calls; verified vs verified sources only)

1. Email/WhatsApp invoice arrives inside a real thread (or later lookalike thread) — recognized pattern in §1 cases and the FBI/NCSC/Scamwatch advisories.
2. AP reads → updates beneficiary in ERP/net-banking → maker-checker or one-screen approval (varies by org maturity).
3. Where present: penny-drop/beneficiary name-match = verifies ACCOUNT EXISTENCE/NAME, not the instruction's authority.
4. Payment run (immediate/next-day). Discovery usually occurs when the supplier chases non-payment (days to weeks later; recovery unlikely — 24% never recoup, AFP).
5. The proposed Stage-1 object of test: an independent confirmation of the exact change on the supplier's pre-registered channel + a portable authorization record (Persona E probe). Nothing built — hypothesis staged for the conversations.
